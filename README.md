# Akinbola Daniel — Portfolio

Personal portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Edit content

- `src/data/profile.js` — name, bio, skills, email, GitHub, LinkedIn
- `src/data/projects.js` — projects (problem, solution, features, tech, links)

## Deploy

Push to GitHub, then import the repo on Vercel (framework preset: Vite).
